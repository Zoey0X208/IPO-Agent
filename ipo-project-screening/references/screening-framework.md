# 企业池筛选框架

## 输入及使用限制

输入为运营方配置 `selection_context` 与企业 `evidence_packages`。每个证据包仅由已勾选Excel字段整理而来，且不包含本地预设的“候选/培育/暂缓”结论。详细字段边界见[Excel勾选字段边界](excel-selected-data-boundary.md)。

| 证据维度 | 可用来源 | 可以做的事 | 不能做的事 |
| --- | --- | --- | --- |
| 主体与策略匹配 | 企业登记基本信息、存续登记 | 识别行业/经营范围与运营方配置的文本匹配；归一名称 | 推断融资意向、企业阶段、上市计划或区域战略 |
| 股权与出资 | 股东及出资、股权出质 | 提示出资、出质记录和后续核验需求 | 确认实控人、代持、对赌、完整股权沿革 |
| 经营财务 | 企业年报、税务指标、纳税、银行流水 | 判断不同财务证据是否齐备、提出交叉核验 | 宣称审计确认、计算估值、将流水/税额当收入或利润 |
| 技术创新 | 专利、创新评价 | 提示技术/创新评价证据可得性 | 确认技术壁垒、市场地位、客户验证或科创属性 |
| 合规 | 严重违法、失信被执行、海关失信、行政处罚 | 对已提供记录提出事项、状态、整改与影响核验 | 对未提供记录判定“无风险”，或直接作重大性、法律结论 |

## 五张证据卡的阅读顺序

1. **经营与财务证据**：看年报、税务、纳税和银行流水是否同时可得，是否存在可交叉核验的入口。没有审计报告、收入确认、客户合同等字段时，相关结论必须为待核实。
2. **股权与出资证据**：看是否有出资、实缴和出质记录。它们只能形成核验清单，不能替代实际控制人和完整沿革核查。
3. **技术与创新证据**：看专利和创新评价是否可得；只作为业务实质的线索。
4. **合规证据**：对输入中存在的处罚/失信/出质记录，提出获取文书、履行凭证、整改验收及持续影响说明的需求。没有输入不作反向推断。
5. **投行服务时点与策略匹配**：可使用行业/经营范围与运营方重点行业的文本匹配；融资需求、现有中介、联系人、决策链均不存在于当前输入，默认写为待核实。

## Skill 自主筛选原则

以下是判断顺序，不是代码阈值或数值评分：

1. 先检查输入能否归一到明确主体，以及核心证据是否来自允许字段。
2. 将明显风险记录与“未提供风险记录”严格区分；前者进入核验优先级，后者仍是信息缺口。
3. 在同一批企业中比较：证据完整度、财务交叉核验入口、专利/创新线索、风险事项的可核验性，以及与运营方配置的匹配度。
4. 选择少量“优先接触”企业时，应解释为什么该企业在当前证据边界内比其他企业更适合先投入资料沟通资源；为每家入选企业列出一个最大待验证假设及其最短核验动作，不是证明其可上市或必然融资。
5. 对已出现的出质、处罚、失信、严重违法或财务口径线索，以 M1/M2/M3/M8 风险模块登记“触发事项—筛选影响—待补材料—核验动作—核验时点”；详细规则见[预研风险模块与核验闭环](pre-screen-risk-modules.md)。
6. 当任何企业都没有足够的服务时点、融资意向或关键核验材料时，可以不选择 `engage_now`，而全部给出培育/风险整改优先/暂缓；不得为了凑满 `top_k` 而硬选。

## 路径说明

| 路径 | 适用含义 |
| --- | --- |
| `engage_now` | 在本批证据下，建议优先启动通用资料沟通与项目预研；仍需补充融资时点和核心核验材料 |
| `cultivate` | 存在经营、技术或策略匹配线索，但证据不足以支持本周优先投入 |
| `risk_remediation_first` | 已提供出质、处罚、失信或严重违法等记录，先核验事项状态与影响再决定投入 |
| `monitor` | 当前证据覆盖过低，等待后续已勾选字段或授权材料 |
| `not_selected` | 仅在输入存在明确且未闭合的暂缓依据时使用；不能因字段缺失排除 |

`engage_now` 是相对承揽资源的排序，不是上市可行性判断。所有路径均可在取得新材料后调整。

## 所有优先对象的最低核验清单

审计财务和收入确认、经营现金流、实际控制人与完整股权沿革、客户供应商/合同/关联交易、治理内控、重大合规事项、融资决策链及现有中介情况。以上当前均不在勾选输入中，必须标记为待补材料。
