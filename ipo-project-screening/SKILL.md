# IPO 项目承揽与获客筛选

用于投行团队从一批企业中判断哪些企业值得优先投入承揽预研资源。Skill 输出优先接触、条件跟进、培育、风险整改优先、观察或暂缓，但不构成上市资格、板块、融资、法律或审计结论。

## 绝对数据边界

1. 企业事实**只能**使用输入证据包中、来自《数据表信息项-需求-数据探查v2.xlsx》且“纳入需求（投行）=√”的字段。字段范围见[Excel勾选字段边界](references/excel-selected-data-boundary.md)。
2. 不搜索、不补录、不猜测外部企业数据；不得使用融资意向、估值、客户、订单、联系人、审计意见、IPO计划等未在本次勾选范围内的内容。
3. 缺少的字段必须写为“待核实信息”或“信息缺口”；缺少记录不等于不存在风险。
4. `selection_context` 是运营方配置（如优先行业、服务能力、Top K），不是企业事实，不能为企业补充任何业务、财务、风险或关系信息。
5. 不输出个人姓名、联系方式、身份证件、账户、交易对手等敏感信息。银行流水只可作为汇总核验线索，不能直接等同营业收入、利润或融资需求。

## 共同边界

- 不输出数值总分、上市概率、融资成功承诺、投资人意向或申报时间表。
- 每项结论显式标记 `known_fact`、`reasonable_inference` 或 `to_be_verified`；前两类必须引用输入 `evidence_id`。
- 对年报、税务、纳税、流水等数据，仅将其作为可核验经营线索；未提供审计报告和收入确认资料时，不得表述为“审计确认”或“已满足发行条件”。
- 当前勾选字段没有估值和融资转化链条：`valuation` 与 `lead_conversion` 两个视角通常应为 `to_be_verified`。没有可支持个性化触达的信息时，`wechat_first_touch` 必须为 `null`，改为给出非个性化的资料索取或会面建议。

## 工作模式

1. **批量企业池筛选（默认）**：先读[企业池筛选框架](references/screening-framework.md)、[Excel勾选字段边界](references/excel-selected-data-boundary.md)、[预研风险模块与核验闭环](references/pre-screen-risk-modules.md)和[输出模板](references/output-templates.md)。
2. **单企业风险预核查**：仅当输入含对应的已勾选合规、出质、年报、税务或流水证据时，可参照[风险预核查流程](references/risk-workflow.md)提出核验任务；缺失证据不补造。
3. **整改跟踪**：仅对输入已有的处罚、失信、出质或其他风险记录提出闭环核验，不能虚构责任人、时限或整改完成状态。

## 批量筛选流程

1. **先确认实体与输入边界**：统一社会信用代码一致才可自动合并。企业简称仅来自已勾选的 `qyjc`；相似名称但信用代码不同或缺失时不得合并。
2. **阅读五类证据卡**：经营财务、股权出资、技术创新、合规、投行服务时点与策略匹配。最后一类因当前字段无融资/联系人信息，通常只可作“待核实”。
3. **由本 Skill 作相对筛选**：以证据完整性、经营交叉核验可行性、技术创新线索、合规风险是否可核验、与运营方策略的文本匹配等作批量比较；不以单一收入、利润、专利数量或单条风险记录直接决定排序。
4. **先写最大待验证假设**：每家 `engage_now` 企业必须给出一个最影响继续投入承揽预研资源的假设，说明影响、证据编号与最短核验动作。不得把IPO可行性或融资意向作为假设。
5. **登记预研风险模块**：仅对输入已出现的线索，在 M1（主体与出资）、M2（股权出质）、M3（财务口径核验）、M8（法律合规）中登记风险闭环：触发事项 → 筛选影响 → 待补材料 → 核验动作 → 核验时点。不要为凑模块而虚构发现，也不要作红黄绿或上市障碍判断。
6. **形成可执行但不越界的动作**：所有“优先接触”均要写明下一步资料索取/管理层会面主题、核验事项和工作日。若缺乏联系人和融资意向，首触策略只能是通用的资料沟通建议，不得生成个性化微信文案。

## 输出

严格遵循[批量承揽筛选JSON契约](references/output-templates.md)。每家企业只能在一个处理路径中出现。路径和排序由本 Skill 决定；本地代码只提供来自已勾选Excel字段的证据包。

## 项目推进前的最低核验

即使列为优先接触，仍需在取得授权后核验审计财务、收入确认、经营现金流、实际控制人与完整股权沿革、客户供应商/合同/关联交易、治理内控、重大合规事项及融资决策链。这些均是当前输入外的**待补材料**，不是已知事实或可申报结论。
